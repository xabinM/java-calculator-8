# java-calculator-precourse

# 기능 요구 사항

## 개요
사용자가 입력한 문자열에서 숫자를 추출하여 더하는 계산기를 구현한다.

## 기능 상세
1. 기본 구분자 쉼표(,), 또는 콜론(:)을 기준으로 사용자 입력을 구분한다.
2. 기본 구분자 외에 사용자 입력 시작부분에 "//" 와 "\n" 사이에 위치하는 커스텀 구분자가 있을 수 있다.
3. 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후 애플리케이션은 졸료되어야 한다.

## 입출력 요구 사항
### 입력
- 구분자와 양수로 구성된 문자열
### 출력
- 덧셈 결과
``` 
결과 : 6
 ```
### 실행 결과 예시
```aiexclude
덧셈할 문자열을 입력해 주세요.
1,2:3
결과 : 6
```

## 예외
### 예외 사항
1. 잘못된 입력값
```
ex) 1,2.3
```
2. 양수가 아닌, 0 또는 음수 입력
```aiexclude
ex) 1,2,-3
```
3. 커스텀 구분자가 여러개?
```aiexclude
ex) //./\n1,2,3
```
4. 입력 스트링이 비어있을 때
```aiexclude
ex) //.\n
```
